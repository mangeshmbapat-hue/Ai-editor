# Social media logo library (owner-supplied)

The owner's images of the social platforms, for the Faceless Editor (owner rule 2026-11-10). When a VO names a platform, or talks about social media in general, use these logos in the animation instead of generic heart or message icons.

| Platform | File | Said in the VO as |
|---|---|---|
| Facebook | `facebook.png` | Facebook, FB, फेसबुक |
| X (Twitter) | `twitter.png` | Twitter, X, ट्विटर |
| Instagram | `instagram.png` | Instagram, Insta, इंस्टाग्राम, इंस्टा |
| WhatsApp | `whatsapp.png` | WhatsApp, व्हाट्सऐप, व्हाट्सएप |
| Snapchat | `snapchat.png` | Snapchat, स्नैपचैट |

- Only the owner's own files go here. Keep the original files unchanged; scale and animate copies in the job folder.
- "social media" or "सोशल मीडिया" without a platform name: use 3-5 of these logos together.
- Each logo comes in with a smooth animation, sits still, and leaves smoothly (no shake).
