# TV and news media logo library (owner-supplied)

Owner rule (2026-11-10): when a VO talks about the media or a news channel, use the real channel logos (Aaj Tak, ABP News and others). Only the owner's own files go here, as `<channel>.png`, for example `aajtak.png` and `abp.png`. They are not downloaded from the internet. Ask the owner for a logo the first time a VO needs it.
